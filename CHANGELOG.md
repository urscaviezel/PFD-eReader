## Beta v0.2.0 – 2026-10-19

First public version.

- New formats: CBR, CB7, CBT, FB2 / FB2.ZIP, HTML, Markdown; archive type is detected from the content
- Progress bar while a CBR/CB7 is unpacked the first time
- Foveated rendering (default: High) and the headset's refresh rate is used (72/80 Hz recommended)
- Book collides with furniture and walls
- App info with licenses, update check and in-app installation of new versions
- TV keeps playing when you change rooms; guides updated (EN/DE/FR)
- Signed with a new release key – uninstall earlier betas once

Erste öffentliche Version.

- Neue Formate: CBR, CB7, CBT, FB2 / FB2.ZIP, HTML, Markdown; Archivtyp wird am Inhalt erkannt
- Fortschrittsbalken beim ersten Entpacken von CBR/CB7
- Foveated Rendering (Standard: Hoch), die Bildwiederholrate des Headsets wird übernommen (72/80 Hz empfohlen)
- Das Buch kollidiert mit Möbeln und Wänden
- App-Info mit Lizenzen, Update-Suche und Installation neuer Versionen direkt aus der App
- Fernseher läuft beim Raumwechsel weiter; Anleitungen aktualisiert (DE/EN/FR)
- Mit neuem Release-Schlüssel signiert – frühere Betas einmalig deinstallieren
